# Rubric — LeetCode / Algorithms Interview

Score each dimension 0–5. 4 = "would pass a senior loop on this problem."

| Dimension | 0–1 | 2–3 | 4–5 |
|---|---|---|---|
| **Communication** | Silent or unclear | Explains after prompting | Narrates plan + tradeoffs proactively |
| **Correctness** | Wrong / doesn't run | Works on happy path | Handles edge cases, verified |
| **Runtime** | No complexity analysis | States complexity when asked | Derives + justifies optimal complexity |
| **Tradeoffs** | None | Mentions one | Compares approaches, picks with reason |
| **Optimization** | Stuck at brute force | Reaches a better solution slowly | Reaches optimal, explains the insight |
| **Edge cases** | Ignores | Some, after prompting | Enumerates unprompted, tests them |

## Process checklist (penalize skipped steps)
- [ ] Clarified inputs, constraints, expected I/O before coding
- [ ] Stated brute force + its complexity first
- [ ] Optimized with a named technique/data structure
- [ ] Coded cleanly, meaningful names
- [ ] Tested on edge cases (empty, single, duplicates, max size)
- [ ] Stated final time + space complexity

## Notes for the interviewer
Record the **highest hint-ladder rung** used and the time to first correct plan. Both
feed the readiness score. Jumping to code before a plan caps Communication at 2.
