# Curated Resources

Pointers the engines can recommend. Keep this lean and high-signal — a short list you'd
actually use beats a link dump. Add to it as better resources surface during sessions.

## Algorithms & Data Structures
- **NeetCode 150 / roadmap** — pattern-organized problem set; the backbone of DSA practice.
- **LeetCode** — problem source; use the "Blind 75" as a first pass.
- **"Grokking the Coding Interview"** — pattern-first framing (sliding window, two pointers, etc.).
- **CLRS** (reference, not front-to-back) — for rigor on a specific algorithm.

## System Design
- **"System Design Interview" (Alex Xu), Vol. 1 & 2** — the standard mid→senior prep.
- **ByteByteGo** — visual refreshers on components (queues, caching, replication).
- **"Designing Data-Intensive Applications" (Kleppmann)** — the depth source for storage,
  replication, consistency. Read a chapter per relevant node.

## Databases (Postgres)
- **Postgres docs — Indexes & EXPLAIN** — primary source for `sql-indexes`/`transactions`.
- **Use The Index, Luke!** — indexing intuition.
- **Supabase docs** — RLS, auth, and Postgres-in-practice for the student's stack.

## Web / Stack
- **React docs (react.dev) — "Render and Commit", "You Might Not Need an Effect"** — for `react-rendering`.
- **Next.js docs — App Router, Server vs Client Components**.
- **Node.js docs — the Event Loop guide** — for `node-event-loop`.
- **MDN — HTTP** — for `http`.

## Behavioral / Communication
- **"Cracking the Coding Interview" — behavioral chapter** — STAR structure.
- Keep a personal **stories bank** (in `projects/`) mapped to common prompts.

## Meta
- **Anki / spaced repetition** — the review-queue mirrors this; export cards for concepts
  you want to drill outside sessions.
